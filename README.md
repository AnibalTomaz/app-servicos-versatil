# APP SERVIÇOS VERSÁTIL v2.60

Correção do Admin em Lazer e Conveniência.

- Toda categoria/subcategoria do tipo menu passa a exibir ações explícitas para editar, criar subcategoria, criar item e excluir.
- O botão principal cria uma categoria (menu), não um local.
- Dentro de cada categoria há dois comandos separados: `+ Subcategoria` e `+ Item`.
- `+ Subcategoria` abre o editor já como Menu/Submenu.
- `+ Item` abre o editor já como Local/Estabelecimento.
- Categorias recém-criadas passam imediatamente a oferecer criação de itens dentro delas.
- Mantidas as correções e dados das versões anteriores.
- O pacote não contém data.json.
